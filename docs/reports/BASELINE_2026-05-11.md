# Criterion 基线数据 — 2026-05-11

> T-A1: 首次 Criterion benchmark baseline 收集  
> 平台: Windows 11, Rust stable, release build  
> 报告路径: `target/criterion/`

---

## scanner 块哈希基准（`syncthing-fs/benches/scanner.rs`）

| 文件大小 | 耗时 (median) | 吞吐量 (median) |
|----------|---------------|-----------------|
| 64 KiB   | 184.71 µs     | **338.37 MiB/s** |
| 1 MiB    | 654.61 µs     | **1.49 GiB/s** |
| 16 MiB   | 9.99 ms       | **1.56 GiB/s** |

**观察**:
- 大文件（1 MiB+）已接近 SHA-256 的硬件极限（1.5+ GiB/s）
- 64 KiB 小文件存在文件 I/O 开销（仅 338 MiB/s）
- 现有 rayon 线程池已在工作（T-B1 验证: 多 worker 并行）

**100 samples 测量稳定性**:
- 64 KiB: 7% 离群（mild）
- 1 MiB: 8% 离群（mild + severe）
- 16 MiB: 1% 离群
